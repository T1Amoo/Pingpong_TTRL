# A1 反手 v6：速度质量与挥拍回撤

v6 是独立的新任务，不改变 v5 的 task、实验目录、watchdog 或 checkpoint。
它完整继承 v5 的发球分布、相机延迟、执行器随机化、接触材料、回球结果梯子和
`weak_topspin`，只调整击球前奖励语义。

## 奖励变化

控制周期为 `dt=0.02 s`：

- 接触锁存的前向拍速质量：`weight=100`，`0.4 m/s` 以下为 0，
  `1.6 m/s` 以上为 1，单次贡献限制在 `[0,+2]`；
- 击球前最大前伸位置的回撤：4 cm 内免费，12 cm 达到满惩罚，
  `weight=-40`，单次最低 `-0.8`；
- 若整球都没有回到 `hit_plane_x-0.08 m` 后方完成一次有效起挥准备，
  首次接触按满回撤惩罚结算，避免长期把球拍停在击球面前方绕过约束；
- 击球点稠密引导只保留 y/z，`weight=0.5`，不规定 x 位置路线；
- 近球且 y/z 对齐后的 forward swing-through 保留 `weight=0.75`，
  速度封顶 `1.6 m/s`，单步最多 `+0.024`；
- 提前前伸、临击后撤、接触横向拍速和预测桌外落点权重均为 0；
- v5 的接触、过网、物理上台、真实落点中心奖励及弱上旋原样继承。

`precontact_drawdown_tracking_enable` 只在 v6 打开；共享环境会为历史任务分配
几个很小的兼容 buffer，但 v5 不更新或消费这套状态，奖励和动作语义保持不变。
