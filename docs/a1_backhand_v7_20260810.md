# A1 反手 v7：1.08 m 固定升降资产与新默认姿态

日期：2026-08-10。

## 版本结论

反手 v7 以 v6 为唯一基线，从零训练。相对 v6 的有意差异为：

1. 机器人资产从 1.15 m 的 `X1_URDF_V1_3_paddle.usd` 切换为独立的
   `X1_URDF_V2_paddle.usd`；
2. 右臂默认关节位置改为
   `[1.369, -0.651, 1.656, -1.767, 0.145, 0.684, -2.153]`；
3. 为避免二阶响应模型仍围绕旧姿态做仿射缩放，`action_response_u_mean`
   同步重锚到上述新默认位置；
4. 开启可复制的定向自碰撞，只保留球拍与 `base_link` 的物理碰撞；
5. 新增球拍—机身安全距离惩罚、持续侵入终止和击球后的安全回撤奖励。

除上述安全与回撤项外，原有奖励、发球分布与课程、相机延迟、predictor、
动作延迟、逐关节低通、二阶响应的 fn/zeta/delay/gain/bias、DR、接触参数、
spin、PPO 参数和总轮数全部继承 v6。

## 1.08 m 资产

V2 URDF 由 V1_3 独立派生，`sj` 继续是 fixed joint，只把其 origin z 下移
`0.07 m`：

```text
base_z 0.0282
+ sj_origin_z 1.02680245585163
+ r0_origin_z 0.0250000000004311
= r1 centerline_z 1.080002455852061 m
```

V1_3 的 1.15 m URDF/USD 未修改、未覆盖。V2 复用未变化的 CAD mesh，但拥有
独立 URDF、根 USD、base/physics/sensor USD 层和 converter config。训练入口
额外套用 `X1_URDF_V2_paddle_self_collision.usda`：明确过滤 31 个刚体内部
465 对中的 464 对，只保留 `Link_r_paddle` 与 `base_link` 的碰撞。这里不用
collision-group prim，因为它不能被 Isaac 的多环境复制；也不使用指向
articulation root 的简写，因为 PhysX 不会据此展开所有内部刚体对。

## 回撤与机身安全边界

- ready pose 的离线网格间距约 `10.58 cm`，在线球拍轮廓—机身胶囊代理约
  `10.44 cm`；4096 环境随机初始化后的实跑最低约 `7.57 cm`；
- `6.5 cm` 开始连续惩罚，`3.5 cm` 达到满惩罚，并在连续两个 control step
  低于该值时终止；这样在随机 ready pose 下仍留约 `2.1 cm`，标称姿态下留
  约 `3.9 cm` 的装配、USD 凸包、标定与结构形变裕度；
- 击球后只奖励从击球平面回撤至 ready 点前方 `4 cm`，即约 `15.9 cm`
  回撤；继续向身体深撤不再增加奖励；
- 回撤奖励只在确认球拍触球且出球状态已锁存后开启，间距低于 `6.5 cm`
  时回撤奖励归零，由安全惩罚接管。

## 训练入口

```text
task:       a1_tt_backhand_v7
eval task:  a1_tt_backhand_v7_eval
experiment: a1_tt_backhand_real_v7_r108_readypose
run:        scratch_r108_selfcollision_bodyclear65mm_saferetract_5k10k5k
target:     model_19999.pt (20000 iterations)
watchdog:   watchdog_a1_tt_backhand_v7.sh
```

首次启动必须确认云端 experiment 目录不存在，保持 `resume=False`，不从 v6
checkpoint warm-start。watchdog 只允许在 v7 自己产生 checkpoint 后恢复 v7。

## 已完成验证

- V1_3/V2 URDF XML 与 sj fixed 状态检查；
- V2 USD 由 IsaacLab 2.1.1 重新导出；
- USD stage 读回 `Link_r0 z=1.051802396774 m`，加 base spawn z 后为约 1.08 m；
- v6/v7 train 与 eval 配置逐字段比较：仅 USD、r1--r7 默认值和 response u_mean
  的基线迁移保持不变，安全层为 v7 独立新增；
- `a1_tt_backhand_v7` 本机 2 env、1 iteration PPO+predictor 冒烟通过，生成
  `model_0.pt`，发球拒绝采样为 `sampled=2/accepted=2/fallback=0`。
- 定向碰撞层 4 env、300 control-step 零动作测试无 reset，最小在线安全间距
  `8.71 cm`；旧 v7 `model_1900.pt` 回放约 `28.9%` 样本进入软边界、约
  `5.6%` 被安全终止，说明旧策略确实依赖了不安全回撤。
- 云端正式 4096-env 训练在 commit `c344461` 从零启动；iter60 的 mean reward
  为 `17.08`、value loss 为 `0.5115`，回撤奖励和安全距离惩罚均有有限值。
  首个 1200-control-step 累计安全窗口中，软边界、硬边界和持续侵入终止比例
  分别为 `0.9529%`、`0.1124%` 和 `0.0499%`，显著低于旧策略回放；窗口内
  最低代理间距为 `-0.69 cm`，因此物理自碰撞和持续侵入终止仍必须保留。
