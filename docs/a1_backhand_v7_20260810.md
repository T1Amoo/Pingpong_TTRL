# A1 反手 v7：1.08 m 固定升降资产与新默认姿态

日期：2026-08-10。

## 版本结论

反手 v7 以 v6 为唯一基线，从零训练。相对 v6 只允许以下三类差异：

1. 机器人资产从 1.15 m 的 `X1_URDF_V1_3_paddle.usd` 切换为独立的
   `X1_URDF_V2_paddle.usd`；
2. 右臂默认关节位置改为
   `[1.369, -0.651, 1.656, -1.767, 0.145, 0.684, -2.153]`；
3. 为避免二阶响应模型仍围绕旧姿态做仿射缩放，`action_response_u_mean`
   同步重锚到上述新默认位置。

奖励、发球分布与课程、相机延迟、predictor、动作延迟、逐关节低通、
二阶响应的 fn/zeta/delay/gain/bias、DR、接触参数、spin、PPO 参数和总轮数
全部继承 v6。

## 1.08 m 资产

V2 URDF 由 V1_3 独立派生，`sj` 继续是 fixed joint，只把其 origin z 下移
`0.07 m`：

```text
base_z 0.0282
+ sj_origin_z 1.02680245585163
+ r0_origin_z 0.0250000000004311
= r1 centerline_z 1.080002455852061 m
```

V1_3 的 1.15 m URDF/USD 未修改、未覆盖。V2 复用未变化的 CAD mesh，但拥有
独立 URDF、根 USD、base/physics/sensor USD 层和 converter config。

## 训练入口

```text
task:       a1_tt_backhand_v7
eval task:  a1_tt_backhand_v7_eval
experiment: a1_tt_backhand_real_v7_r108_readypose
run:        scratch_r108_readypose_speedquality_drawdown_yzonly_weakspin_5k10k5k
target:     model_19999.pt (20000 iterations)
watchdog:   watchdog_a1_tt_backhand_v7.sh
```

首次启动必须确认云端 experiment 目录不存在，保持 `resume=False`，不从 v6
checkpoint warm-start。watchdog 只允许在 v7 自己产生 checkpoint 后恢复 v7。
