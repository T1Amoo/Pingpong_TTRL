# A1 反手 v5：hit-first 正奖励阶梯、x 阶段门控与微弱上旋

日期：2026-08-07

## 1. 为什么另起 v5

v4 在 v3 的可击球策略上同时加入提前前伸、临击后撤、接触横向拍速、桌外落点四个负项，并把接触方向奖励从 8 提到 20。训练很快找到“少动就少扣分”的局部最优：同轮次的接触与上台明显低于 v2/v3，play 也缺少明确击球动作。

v5 不覆盖 v4，保留全部 v4 run/checkpoint。v5 继续继承 v4 已校准的机器人、相机、执行器、接触材质、平移发球和真实击球面 predictor 标签，只修改奖励、x 阶段时机和反弹后 spin。

## 2. 奖励原则

目标顺序是：

`没接到 < 有效接触但未上台 < 真实上台 < 真实落在台面中心附近`

Isaac RewardManager 会乘 `dt=0.02 s`。下表是一次事件的最大增量，不含一直存在的低权重动作正则：

| 事件 | raw weight | 单次最大增量 | 说明 |
|---|---:|---:|---|
| 有效接触事件 | 250 | +5.0 | 与接触质量无关，保证任何有效接触优于漏球 |
| 接触质量 | 50 | +1.0 | 保留连续梯度，但不再主导策略 |
| 甜区 | 50 | +1.0 | 接触质量塑形 |
| 预测过网 | 180 | +3.6 | 正值代理，无失败负值 |
| 预测落点中心 | 200 | +4.0 | 50 cm 处仍为 +2.0；桌外也不扣分 |
| 真实对方台反弹 | 550 | +11.0 | 大于所有有界接触塑形与预测代理的最坏差额 |
| 真实反弹点中心 | 400 | +8.0 | 物理反弹点 `(0.70, 0)` 的高斯核；50 cm 处 +4.0 |

真实反弹点会在 500 Hz 物理子步检测到反弹时锁存，中心奖励不使用预测落点。这样“预测会落台但实际没落台”不能拿到真实上台或中心奖励。接触速度奖励在 3 m/s 封顶；即使比较“所有接触塑形和预测代理均满分的桌外球”与“落在最远台角、其它塑形均为零的上台球”，后者的 sparse outcome 预算仍更高。

若接触、post-impact 或真实反弹恰好发生在 ball-timeout 的同一个 control tick，v5 会把 reset 推迟到 RewardManager 消费事件之后；post-impact 尚未结算时最多按既有 60 ms 窗口等待，避免边界 tick 把 `+5/+11/+center` 清掉。

关闭的约束：

- 临击后撤惩罚：0
- 接触横向拍速惩罚：0
- 预测桌外惩罚：0
- 接触方向奖励：20 降回 v3 已验证的 8，仍使用 v4 正确的接触前状态锁存

v5 新增的挥拍负项只有提前前伸。继续继承 v3 已验证的“拍子相对预测点高出 12 cm”保护、通用 action/joint 正则和防前臂挡球安全项；它们不是造成 v4 collapse 的新增约束，也不限制绝对高球高度：

- 提前前伸：最终 weight=-0.5，且前 1000 iter 为 0，1000--4000 iter 逐渐启用；
- 旧的相对高位保护：weight=-4，随每个球的预测 z 一起移动。

## 3. x 奖励是阶段门控，不再缩放 dx

v4 把 `dx` 乘 `clip(1-t_hit/0.45, 0.1, 1)` 后再并入唯一的三维距离。这既不是清晰的动作阶段，也会让奖励几何随时间连续变形。

v5 改为两个非负项：

1. 整个来球阶段始终给 `y/z` 到真实击球面交点的正奖励；
2. `t_hit` 跨过临界点后，才开启 x 向前进度：离击球面 22 cm 外为 0，进入到 2 cm 内逐渐升至 1，并乘以当前 y/z 质量。

门控从关闭到打开只用 40 ms（两个 50 Hz tick）的 smoothstep，开门只会增加奖励，不会让同一状态突然减分。ready 拍心离击球面约 19.7 cm，开门时 x bonus 只有最大值约 1.3%，但已经有朝击球面前进的梯度；这样既不奖励驻留 ready，也不会留下 ready 到 8 cm 之间长达 11.7 cm 的零梯度死区。门控使用 reset 时物理预积分得到、随 episode 单调递减的 `ball_future_t`，不用会随快慢球改变含义的固定球 x，也不用抖动的在线 predictor 输出。

时机课程：

- 0--1000 iter：x 在剩余 0.80 s 开启，提前前伸惩罚为 0，优先发现接触；
- 1000--4000 iter：开启点从 0.80 s 线性收紧到 0.60 s，同时提前前伸惩罚从 0 线性增至 -0.5；
- 4000 iter 后：固定 0.60 s。

提前阶段允许拍心前伸到 `hit_plane_x-0.08=-1.323 m`；测得 ready 拍心约 `-1.44 m`，因此仍有约 11.7 cm 的自由准备区，同时保留约 8 cm 的最终向前挥程。

## 4. Spin

v4 的 32 簇是完整真实数据库的混合三轴 spin，不是“微弱上旋”。全量时模长约为中位 21 rad/s、P95 44 rad/s，并包含侧旋和下旋。

v5 使用单独的 `weak_topspin` sampler：

- easy：模长 2--4 rad/s；
- hard：模长 2--8 rad/s；
- A1 来球沿 `-x`，故上旋固定为 `omega_y<0`；
- 只允许朝 `omega_z` 随机倾斜最多 10 度，`omega_x=0`；
- 不再加 ±15% 幅值 jitter；
- 仍在本方桌真实反弹后注入，Magnus 继续为 0。

因此 spin 只提供真实球拍接触的必要鲁棒性，不改变空中轨迹。若 play 中看到来球本身高或慢，原因是平移发球候选及物理反弹，不是 spin；v5 当前故意保持 v4 的平移发球范围不变，以便只做一个变量的 A/B。

## 6. 验收

纯逻辑回归覆盖：

- v4 旧门控与旧 spin 采样保持不变；
- v5 x 门控早期关闭、临击开启、边界单调；
- 开门不会降低跟踪奖励，ready 只有约 1.3% x 奖励但已有前向梯度，22--2 cm 内严格递增；
- timing curriculum 在 `TT_SIM_STEP_OFFSET` 续训时连续；
- 弱上旋符号、幅值、侧倾范围；
- 最佳桌外 sparse outcome 仍低于最差台角 sparse outcome，台内越靠中心越高；
- v4 新增的后撤、横向拍速、桌外负项均为 0。

运行时验收也已完成：v4/v5 分别构造小环境并实际 step，确认配置隔离；v5
另完成一次 `2 env x 24 steps` 的完整 PPO + predictor 迭代，诊断运行把
`num_mini_batches` 从生产配置的 64 临时降为 4（每批 12 样本），
`value_function/surrogate/entropy/action std` 均为有限值。生产训练仍使用
4096 env 和 64 mini-batches，不继承这个小样本诊断覆盖。
